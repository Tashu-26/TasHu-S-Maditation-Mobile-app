# TasHu’S Maditation
### Smart Crochet Companion 🧶

TasHu’S Maditation is a mobile application designed to help beginner and experienced crocheters manage their crochet activities in one place.

The application aims to make crochet easier through pattern discovery, yarn management, project organization, color combination suggestions, cost calculation, and learning resources.

## Project Overview

The project is being developed using Flutter to create a modern, user-friendly mobile experience.

### Main Features

- Crochet pattern discovery and management
- Yarn stash management
- Crochet project organization
- Color combination helper
- Project cost calculator (BDT ৳)
- Crochet learning resources
- Tutorial Simplifier
- Personal crochet studio

## Getting Started

1. Clone this repository.
2. Open the project in Android Studio or VS Code.
3. Make sure Flutter SDK is installed.
4. Run:

```bash
flutter pub get
flutter run
```
